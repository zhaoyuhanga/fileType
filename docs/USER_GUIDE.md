# 用户手册（USER GUIDE）

按**你要做什么**找，不按代码结构组织。安装与首次启动见 `README.md`；
出问题见 `docs/TROUBLESHOOTING.md`；改代码见 `docs/CONTRIBUTING.md`。

---

## 0. 三个通用概念

**六个板块**：书库 · 转换 · 乐库 · 影视 · 图库 · 文档。顶栏点板块名切换，
首页卡片也能进。板块**第一次打开会慢一点**（按需加载，约 0.2–0.4 秒），之后是瞬时的。

**设置是分板块的**：顶栏「⚙ 设置」打开的是同一个对话框，左侧按板块分页
（通用 / 大模型 / 书库 / 转换 / 文档 / 乐库 / 影视 / 图库）。
每个板块顶栏里也有自己的「⚙」，会直接定位到该板块那一页。

**数据都在一个地方**：`%APPDATA%\ModuWorkbench\modu.db`（单库）。
备份 = 复制这个文件（应用关闭时）；想换机器就把它一起带走。

## 1. 我想读书

**入口**：书架 → 「导入」

| 我要 | 怎么做 |
|---|---|
| 导入书 | 书架 → 导入 → 选文件或**整个目录**（递归扫，只认 `.txt` / `.epub`） |
| 继续上次读的 | 打开应用 → 书架第一本带进度条的就是；或点「阅读历史」 |
| 换阅读主题 | 阅读器右侧「主题」：米白 / 纯白 / 薄荷 / 灰白 / 夜间 |
| 调字号/行距 | 阅读器内的显示设置（不影响其它板块） |
| 从网上找书 | 切换到「在线书库」子页 → 搜索 → 选书 → 下载（见下方合规说明） |
| 删掉一本书 | 书架右键 → 删除（**会同时清掉这本书的阅读进度与历史**） |

**已知限制**：

- 靠**样式排版**（而不是「第X章」这样的标题文字）分章的书，会被识别成一章。
  这种情况仍能正常滚动阅读，只是没有章节跳转；
- 支持 TXT 编码自动识别（UTF-8 / UTF-8-BOM / GBK / GB18030）。若打开是方块字，
  把这本书记给我（`docs/TROUBLESHOOTING.md` 有报告模板）；
- 不认 PDF / MOBI / AZW3。PDF 请用「墨软文档」打开。

**在线书库的合规说明**：在线书源是第三方站点，本项目只做「按需下载」的工具，
不做批量抓取；请自行确认你下载的内容你有权访问。

## 2. 我想转换文件

**入口**：转换板块 → 添加文件 → 选动作 → 开始

**能转的**（输入格式决定可选动作）：

| 类别 | 典型转换 |
|---|---|
| 文本 | txt / md / html / json / xml / csv / tsv / ini 互转 |
| 文档 | docx → pdf / txt / md；pdf → txt / md |
| 表格 | xlsx / csv 互转 |
| 图片 | jpg / png / webp / bmp / tiff / ico / gif 互转，含尺寸与质量 |
| 媒体 | 音频（mp3/wav/flac/aac/ogg/opus…）、视频（mp4/mkv/avi/mov/webm…） |
| 归档 | zip / tar / tar.gz / tar.bz2 / tar.xz / gz / bz2 / xz 解压；rar 解压 |

**几个实用点**：

- **批量**：一次拖入多个文件，动作会对每个文件都执行；
- **转换 → 加入书库**：转换产出的 TXT/EPUB 可以一键进书库（跨板块联动）；
- **Office 高保真**：docx/xlsx → PDF 走 LibreOffice（`soffice`）。
  没装 LibreOffice 时会提示并降级；可在「设置 → 转换」里手动指定 `soffice` 路径；
- **RAR 解压**需要系统的 `unrar` 或 `7-Zip`。

**诚实的限制**：Office → PDF 的保真度取决于 LibreOffice，复杂排版（页眉页脚浮动框、
宏）可能走样；需要像素级还原请用 Office 自己导出。

## 3. 我想听音乐

**入口**：乐库板块，五个子页：搜索 / 曲库 / 歌单 / 转换 / 历史

| 我要 | 怎么做 |
|---|---|
| 搜歌 | 「搜索」输入关键词 → 选源 → 试听或下载 |
| 建歌单 | 「歌单」→ 新建 → 从曲库拖入 |
| 只留完整版 | 设置 → 乐库 → 「最短完整时长」：把试听片段挡掉 |
| 转换成其它格式 | 「转换」子页，或直接用转换板块 |
| 看最近听了什么 | 「历史」子页 |

**已知限制**：在线源返回的可能是试听片段或失效链接 —— 表现为「能搜到、点了没声音」。
用「最短完整时长」过滤能挡掉大部分。播放条是常驻的，切到别的板块音乐不会停。

## 4. 我想看影视

**入口**：影视板块，三个子页：搜索 / 片库 / 历史

| 我要 | 怎么做 |
|---|---|
| 找片 | 「搜索」输入片名；可先在设置里勾选启用的源 |
| 看动漫 | 「搜索」后在**类型**里选「动漫」（原「墨软动漫」板块已移除，动漫由这里承担） |
| 换源 | 详情页选「其它源」；播放卡顿会自动降档/换源 |
| 下载后离线看 | 详情页 → 选集 → 下载；片库 → 已下载可本地播放 |
| 调画质 | 设置 → 影视 → 播放质量（`auto` 会按实测带宽选档） |
| 硬解 | 设置 → 影视 → 硬件解码；**改完要重开播放窗口**（必要时重启应用） |
| 弹幕 | 播放器内打开弹幕面板（弹弹play 源，只读） |

**已知限制（重要）**：

- 影视依赖**第三方聚合接口站**。站点换域名/加校验 → 搜索失败或播放打不开。
  这不是软件能修的，**换源**即可；
- 本项目**不内置浏览器内核**，所以"播放地址要网页 JS 现算"的站点播不了；
- 弹幕只有弹弹play 一个源（它需要读弹片的公开接口）；
- 播放器 F12 诊断面板能看到「回源慢」还是「解码慢」，据此决定换源还是调硬解。

## 5. 我想管照片

**入口**：图库板块，子页：浏览 / 大图

| 我要 | 怎么做 |
|---|---|
| 导入照片 | 浏览页 → 导入目录（递归扫描） |
| 按时间/相机/地点看 | 左侧导航树：相册 / 标签 / 时间线 |
| 打标签、加相册 | 选中图片 → 右侧面板 |
| 简单修图 | 大图页 → 编辑（裁剪/旋转/亮度对比度等） |
| 让画面更好看 | 大图页 → 增强（去噪/锐化/超分/通道运算，**本地算法，无需联网**） |
| AI 推断标签 | 大图页 → AI 标签（需要先在「设置 → 大模型」配好模型） |
| 去重 | 导入时按内容哈希（sha256）自动识别重复 |

**隐私说明（重要）**：AI 有两条路径 ——
「只发元数据」模式**不上传图片**，只把文件名/EXIF/尺寸发给模型；
「AI 分析图片」需要上传缩略图，是否允许由「设置 → 图库」里的授权开关控制。
默认不授权上传。

## 6. 我想处理文档

**入口**：文档板块，六个子页。这是功能最多的板块。

| 子页 | 你能做什么 |
|---|---|
| **查看/编辑** | 打开 Word / Excel / PDF / Markdown / TXT，直接编辑并保存 |
| **美化** | 公文/报告排版：套模板、统一字号行距、加封面与页码 |
| **填充计算** | Excel 表格：按示例反推填充规则、公式计算、批量生成 |
| **合并** | 两个文档对比差异、合并、生成差异报告 |
| **循环/批量** | 一个模板 + 一份名单 → 批量产出多个文档（如通知书、工牌） |
| **安全** | 脱敏（身份证/手机号）、加解密、水印、查看/导出审计日志 |

**诚实的限制**：

- **Excel 公式**是自研子集，覆盖常用函数与区域引用，但**不保证与 Excel 完全一致**
  （数组公式、易失函数、跨工作簿引用）；算不出来会明确报错，不会静默给错数；
- **PDF 打印**依赖随包的 QtPdf；自检项 `pdf_print_engine` 专门验证它；
- **OCR**（扫描件转文字）是可选能力，需要额外组件，界面会提示缺什么；
- **AI 能力**（润色、摘要、体检）需要「设置 → 大模型」里配置 OpenAI 兼容端点。

## 7. 我想配置大模型

**入口**：设置 → 大模型

支持**任何 OpenAI 兼容端点**（不绑定厂商）：填 `Base URL` + `API Key` + 模型名，
点「测试连接」验证。可以配多个「档案」（不同端点/模型），在文档与图库板块里选用。

**边界**：本项目不做「把文档整本上传」的默认行为，AI 功能都是你主动点才发请求；
发出去的内容以界面提示为准。

## 9. 数据、备份与迁移

| 我要 | 怎么做 |
|---|---|
| 备份 | 关闭应用 → 复制 `%APPDATA%\ModuWorkbench\modu.db` |
| 换电脑 | 带上 `modu.db`；媒体文件（`music/` `video/` `gallery/`）也要一起带走 |
| 从旧版（v0.3.x）升级 | 首次启动自动导入旧分库，旧文件改名为 `*.imported.bak`（不删） |
| 清空媒体缓存 | 设置 → 影视 → 清空分片缓存（会显示占用大小） |
| 彻底重来 | 关闭应用 → 删除 `%APPDATA%\ModuWorkbench\`（**会把书库/曲库/图库记录一起删掉**） |

## 10. 这台机器上跑得动吗

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10/11 64 位（也有 macOS 打包配置，未做完整验证） |
| 磁盘 | 安装后约 382 MB（其中随包 ffmpeg 约 196 MB） |
| 内存 | 启动约 160 MB；播放视频与批量处理图片时会更高 |
| 网络 | 只有在线搜索/下载/大模型/AI 标签/EPS 弹幕需要；离线可用转换、阅读、本地图库 |
| 显卡 | 普通即可；**虚拟机/远程桌面**下播视频可能有兼容问题（软件渲染兜底） |

## 11. 一句话总结各板块的"诚实边界"

- **书库**：排版式分章的书没有章节跳转；不认 PDF/MOBI；
- **转换**：Office 保真度取决于 LibreOffice；RAR 需要系统解压工具；
- **乐库**：在线源可能只给试听片段；
- **影视**：源站改版就得换源；不内置浏览器内核，JS 现算地址的站点播不了；
- **图库**：AI 标签需配模型；默认不上传图片；
- **文档**：Excel 公式是子集；复杂 PDF 排版可能走样。

**这些边界不是"待修的 bug"，是设计取舍**——每一条都在对应的
`docs/BOARDS/<板块>.md` 里写明了原因。发现问题请先看 `docs/TROUBLESHOOTING.md`。
