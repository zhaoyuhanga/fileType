## 3. 为什么移除动漫板块（一句话）

那套「规则驱动采集」的播放地址普遍由站点网页 JS 现算或站点私有加密，而本项目
**不内置浏览器内核**（v1.0.0 起的单栈决策）——实测 KazumiRules 全量 16 条规则：
搜索 11 条可用、详情选集 11 条可用，但**取到播放地址 0 条**。
继续维护只会持续产出"能搜到但播不了"的落差，因此整体移除；
动漫类内容改由「墨软影视」的类型筛选承担（结构化接口，地址可静态解析）。

完整说明见 `CHANGELOG.md` 的 v2.0.0 小节。
